Fórmulas utilizadas

MRU - Movimiento Rectilíneo Uniforme

x = v · t

Posición:

x = x₀ + v · t

Velocidad constante:

v = x / t

Aceleración:

a = 0

MRUV - Movimiento Rectilíneo Uniformemente Variado

Posición:

x = x₀ + v₀ · t + ½ · a · t²

Velocidad final:

vf = v₀ + a · t

Velocidad final al cuadrado:

vf² = v₀² + 2 · a · x

Aceleración:

a = (vf - v₀) / t
