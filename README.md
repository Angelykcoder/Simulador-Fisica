# Simulador Educativo de Física

Proyecto web educativo desarrollado con **HTML, CSS, JavaScript y Bootstrap**, enfocado en la simulación visual e interactiva de movimientos físicos.

El objetivo principal del proyecto es ayudar a comprender conceptos de cinemática mediante escenarios gráficos, controles interactivos, datos en tiempo real, fórmulas y gráficas.

---

## Módulos incluidos

El proyecto cuenta con los siguientes módulos:

1. **MRU y MRUV**
2. **Caída Libre y Tiro Vertical**
3. **Tiro Parabólico**
4. **MCUV / Movimiento Circular Uniformemente Acelerado**

---

## Tecnologías utilizadas

- HTML5
- CSS3
- JavaScript
- Bootstrap 5
- Bootstrap Icons
- Chart.js
